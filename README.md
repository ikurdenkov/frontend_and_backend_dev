# 🛒 Интернет-магазин электроники — комплексное решение

**Учебный проект** по дисциплине «Фронтенд и бэкенд разработка».  
В рамках работы выполнены практические занятия №1–12, реализовано полнофункциональное веб-приложение с аутентификацией, управлением токенами, ролевой моделью и клиентской частью на React.

---

## 📋 Содержание выполненных заданий

### 🔹 Практическое занятие №1. CSS-препроцессоры (SASS)
- Создание стилизованной карточки товара.
- Использование переменных, вложенных селекторов, миксинов.
- Компиляция SCSS в CSS.

### 🔹 Практическое занятие №2. Сервер на Node.js + Express
- Разработан простой CRUD API для товаров.
- Реализованы эндпоинты: `GET /api/products`, `GET /api/products/:id`, `POST /api/products`, `PATCH /api/products/:id`, `DELETE /api/products/:id`.

### 🔹 Практическое занятие №3. JSON и внешние API
- Тестирование собственного API через Postman.
- Работа с внешними API (OpenWeatherMap, ExchangeRate-API).
- Сбор скриншотов и сохранение в репозитории.

### 🔹 Практическое занятие №4. API + React
- Связаны фронтенд и бэкенд.
- Реализован интерфейс управления товарами (список, добавление, редактирование, удаление).
- Использован axios для HTTP-запросов, настроен CORS.

### 🔹 Практическое занятие №5. Расширенный REST API + Swagger
- Добавлена документация OpenAPI (Swagger).
- Эндпоинты задокументированы через JSDoc-комментарии.
- Swagger UI доступен по `/api-docs`.

### 🔹 Практическое занятие №6. Подготовка к контрольной работе №1
- Приложение собрано и протестировано.
- Оформлен README, репозиторий открыт.

### 🔹 Практическое занятие №7. Базовые методы аутентификации
- Хеширование паролей bcrypt.
- Регистрация и вход пользователя.
- Добавлены маршруты `/api/auth/register` и `/api/auth/login`.

### 🔹 Практическое занятие №8. JWT-токены
- Генерация access-токена при входе.
- Добавлен защищённый маршрут `/api/auth/me`.
- Middleware `authMiddleware` для проверки токена.

### 🔹 Практическое занятие №9. Refresh-токены
- Добавлены refresh-токены (долгоживущие).
- Реализован эндпоинт `/api/auth/refresh` для обновления пары токенов.
- Хранение refresh-токенов на сервере с ротацией.

### 🔹 Практическое занятие №10. Хранение токенов на фронтенде
- Токены хранятся в `localStorage`.
- Перехватчики axios автоматически добавляют access-токен в запросы.
- Реализована автоматическая отправка `/refresh` при получении 401.

### 🔹 Практическое занятие №11. Управление доступом на основе ролей (RBAC)
- Добавлены роли: `user`, `seller`, `admin`.
- Middleware `roleMiddleware` ограничивает доступ к эндпоинтам.
- **Права доступа:**
  - **Гость** – только регистрация/вход.
  - **Пользователь (user)** – просмотр товаров.
  - **Продавец (seller)** – создание и редактирование товаров.
  - **Администратор (admin)** – полный доступ (товары + управление пользователями).
