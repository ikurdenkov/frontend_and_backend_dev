# Заметки с напоминаниями и уведомлениями

Полноценное веб-приложение для управления заметками, работающее офлайн, с установкой на устройство, WebSocket-синхронизацией, push-уведомлениями и откладываемыми напоминаниями.

## Технологии
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- PWA: Service Worker, Web App Manifest, App Shell
- Backend: Node.js, Express, Socket.IO, web-push
- HTTPS: локальные сертификаты (mkcert)

## Функции
- ✅ Добавление/удаление заметок
- ✅ Офлайн-режим (кэширование)
- ✅ Установка на рабочий стол
- ✅ Индикатор онлайн/офлайн
- ✅ WebSocket – обновления в реальном времени
- ✅ Push-уведомления о новых заметках
- ✅ Заметки с напоминанием на конкретную дату/время
- ✅ Откладывание напоминания на 5 минут (кнопка в уведомлении)
